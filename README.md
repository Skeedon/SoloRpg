# Solo RPG для Warcraft III 1.26–1.27

Исходники прототипа на JASS, без кастомных моделей. **Это не готовая карта `.w3x`**. Компиляция в старом World Editor пока не подтверждена.

## Как проверить
1. Открой карту в классическом World Editor.
2. Код `src/solo_rpg_ascii_test.j` или `src/solo_rpg_utf8.j` вставь в **пользовательский код карты**, а не в одно действие триггера.
3. Создай один GUI-триггер события `Map Initialization`, в действии Custom Script введи `call InitSoloRPG()`.
4. Сохрани карту. При ошибках пришли `war3map.j` из `.w3xTemp`, поскольку номера строк относятся к сгенерированному файлу.
5. Начинай с ASCII-теста, а потом проверяй русскую версию. При проблемах с кириллицей используй преобразование UTF-8 → Windows-1251 в Notepad++.

Следующий этап: исправить ошибки компиляции, затем реализовать город, торговцев, зоны фарма и систему предметов.

## Если карта запускается, но меню героя не появляется

У GUI-триггера с действием `call InitSoloRPG()` обязательно должно быть событие **Карта — Инициализация карты**. Без события действие не выполняется. Проверь, что триггер включён и не имеет условий. После добавления события сохрани карту и запусти тест (`Ctrl+F9`).
